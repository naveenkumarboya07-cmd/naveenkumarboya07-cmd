## 🚀 Featured Project

### 📧 ReachInbox – Email Outreach Platform

**ReachInbox** is a full-stack email outreach and scheduling platform designed to manage email campaigns and schedule email delivery.

The project focuses on building a reliable backend scheduler using **Redis and BullMQ** instead of traditional cron-based scheduling.

### 🏗️ Technology Stack

```text
Frontend
├── React.js
├── HTML5
├── CSS3
└── JavaScript

Backend
├── Node.js
├── Express.js
└── REST APIs

Database
└── MongoDB

Job Scheduling
├── Redis
└── BullMQ

Email
└── SMTP / Ethereal Email

Deployment
├── Netlify
└── Render
```

### ✨ Key Features

* 📩 Schedule emails for future delivery
* ⏰ Background email processing
* ⚡ BullMQ job queue
* 🔴 Redis-backed job management
* 📊 Email campaign dashboard
* 📨 SMTP email delivery
* 🔄 Persistent scheduled jobs
* 🛡️ Backend API architecture
* 🌐 Frontend and backend deployment
* 📱 Responsive user interface
